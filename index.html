Where it all started

It started with
just a game.

Somewhere on WePlay, two people randomly ended up playing Guess the Drawing together.

Then somehow, one game became a few more... and those few games became almost every day for the next couple of months.

We don't play like that anymore. Maybe we've grown up, maybe we just don't feel like it anymore. 😆 But I'm still glad that little game happened.

Because somewhere between all those drawings, jokes, streaks, reels and random conversations, I found a friend I never expected to find. ♡
